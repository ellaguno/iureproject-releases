# IureProject — descargas / downloads

Instaladores y binarios de **IureProject**, gestión de proyectos de escritorio compatible con
Microsoft Project e integrada con Iurefficient. Desktop project management compatible with
Microsoft Project and integrated with Iurefficient.

Descarga la última versión en [Releases](../../releases). / Download the latest version from
[Releases](../../releases).

| Sistema / System | Archivo / File |
|---|---|
| Linux (Debian, Ubuntu…) | `iureproject_<versión>_amd64.deb` |
| Linux (Fedora, openSUSE, RHEL…) | `iureproject-<versión>-1.x86_64.rpm` |
| Linux (cualquiera / any) | `iureproject-<versión>-x86_64-linux.tar.gz` |
| Windows 10/11 | `iureproject-<versión>-x86_64-windows.zip` |
| macOS 11+ (Apple Silicon e Intel) | `iureproject-<versión>-macos-universal.zip` |

Verifica la descarga / Verify the download: `sha256sum -c SHA256SUMS`.
