# IureProject — descargas / downloads

Instaladores y binarios de **IureProject**, gestión de proyectos de escritorio integrada con
Iurefficient. Desktop project management integrated with Iurefficient.

Descarga la última versión en [Releases](../../releases). / Download the latest version from
[Releases](../../releases).

```bash

sha256sum -c SHA256SUMS
./iureproject-<versión>-x86_64-linux/iureproject
```
